Optional · contactless check-in

Register for face check-in

Face registration is optional. You can always check in with hotel staff. Review the data notice before opening your camera.

WHAT THIS LOCAL DEMO STORES A face template linked to this booking

After you opt in, the camera briefly collects four face descriptors and averages them into one numeric template linked to this booking. Only that template, booking reference, and consent time are saved in this browser on this device. The demo does not save a selfie or video, and it does not upload camera frames. This browser storage is not encrypted; anyone with access to this browser profile could access it.

LIMITED USE Booking check-in and room-entry demo

The browser compares a face only with this reservation’s template when you start arrival check-in or ask to simulate door entry. It does not search other guests or run continuous identification. The template is removed at checkout or sooner if you delete it.

This is a learning prototype: the template stays in this browser and is not protected by a hotel server or encryption. It cannot open a real door or update hotel systems. A live hotel would need a secure backend, published retention rules, stronger identity checks, and an equally available staff-assisted option.
